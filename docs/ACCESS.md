# 访问密码与保存

[返回首页](../README.md) · [模式与日常使用](USER_GUIDE.md)

本指南适用于封装 **1.0.6**。两个应用使用各自独立的网页登录密码；密码用于访问该应用的 HTTPS 网页和桌面，不是 NAS 管理账号、SSH、节点或订阅密码。

## 第一次打开

| 应用 | 默认 HTTPS 入口 |
| --- | --- |
| v2rayN | `https://<NAS地址>:18111/` |
| Clash Verge Rev | `https://<NAS地址>:18112/` |

初次安装在 NAS 上生成自签名证书和随机访问密码。浏览器提示证书不受信任时，先核对目标确实是自己的 NAS，再决定是否信任。

初始访问资料保存在 **fnOS 为该应用分配的 `var/private/access.txt`**，由 NAS 管理员以相应权限读取。`<应用数据目录>` 指该应用自己的 `var` 目录，请先从 fnOS 应用路径确认；不同设备、存储卷和应用不能混用。

```bash
sudo cat '<应用数据目录>/private/access.txt'
```

该文件包含访问口令，权限为 root 专用 `0600`，上级私有目录限制为 `0700`。它不是源码、Release 附件或供所有安装者共用的密码；不要上传或公开该文件。

## 保存密码

- 将两个应用分别记录在自己的密码管理器中，同时记录应用名和访问入口。
- 浏览器可以保存登录密码；更换浏览器、清理浏览器资料或修改密码后，需要重新确认保存记录。
- 保持 NAS 上访问资料原有权限。备份若包含本文件、节点、订阅或 TLS 私钥，应使用受保护的存储。
- 公开问题反馈和截图不包含真实口令、私钥、会话令牌或完整运行配置。

## 在网页中修改密码

1. 使用当前密码登录对应应用。
2. 打开右侧 **访问与安全**，选择 **修改访问密码**。
3. 填入当前密码、新密码和确认新密码，再提交。
4. 成功后该应用的旧网页登录和远程桌面会话失效，使用新密码重新登录。
5. 更新密码管理器或浏览器中保存的记录。

新密码为 **12–128 个字符，UTF-8 编码不超过 512 字节**，允许中文和空格，不接受控制字符或与旧密码相同的新密码。密码中的空格会保留，不会自动裁掉。

修改作用于当前应用，并更新管理员访问记录 `var/private/access.txt`。另一个应用的密码不受影响，节点、订阅、原版客户端配置与 TLS 证书保留。旧版本已有的较短密码在升级时保留；主动设置新密码时使用上述要求。

## 忘记密码

先由 NAS 管理员读取本应用的 `var/private/access.txt`。若记录缺失或需要重置，管理员可在 NAS 本机终端使用随应用提供的重置工具，不必删除应用数据目录。

先确认本应用的安装目录、数据目录和应用类型，再执行：

```bash
sudo python3 '<应用安装目录>/tools/reset_portal_password.py' --app v2rayn --var '<应用数据目录>'
```

Clash Verge Rev 使用 `--app clash`。工具默认以隐藏输入方式询问新密码两次；新旧密码不放在命令行参数中，也不要写进 shell 历史或共享脚本。

工具需要 NAS 的 root 管理权限，只更新所选应用的访问凭据。成功后门户会重新读取凭据并撤销该应用旧会话，通常在下次请求或状态刷新时生效，无需手动重启整个应用。使用新密码登录；节点、订阅、TLS 证书和另一应用的数据保留。

`--password-stdin` 供受控的自动化恢复流程通过标准输入提交两行密码，不用于把密码写入命令参数、文档示例或日志。具体选项可先查看：

```bash
python3 '<应用安装目录>/tools/reset_portal_password.py' --help
```

遇到路径、权限或凭据状态异常时，保留现场和现有备份，按脱敏错误处理；不要通过删除整个 `var`、节点库或私钥来尝试重置登录。

## 更新、重装与卸载

| 操作 | 凭据与配置的处理 |
| --- | --- |
| 上游客户端“一键更新” | 网页访问凭据属于应用运行数据，随原有数据保留 |
| 同应用 ID 的 FPK 升级 | 保留已有访问密码、节点和配置；升级前仍应保存恢复材料 |
| 卸载并选择保留应用数据，再重装 | 以 fnOS 实际保留的数据目录为准，保留下来的凭据可继续使用 |
| 卸载并删除应用数据，或全新安装 | 作为新安装重新生成访问凭据；被删除的配置不由安装包恢复 |

重置网页登录密码不等于回滚上游客户端。右侧的程序版本回滚也不作为找回登录密码的方法。设备地址变化或证书调整应由管理员单独规划，不需要为此清空节点和整个应用数据目录。
