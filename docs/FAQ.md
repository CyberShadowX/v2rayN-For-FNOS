# 常见问题

[返回首页](../README.md) · [使用指南](USER_GUIDE.md) · [访问密码](ACCESS.md)

## 是 Docker 应用吗

这是 FPK 原生封装，使用宿主图形环境运行官方 Linux 桌面客户端，并通过 HTTPS 网页桌面操作。运行本应用不依赖 Docker；网络接管可供 NAS 中已有容器使用。

## 文件名 x86 是 32 位吗

`x86` 是飞牛包架构标记。客户端与网络组件载荷为 **64 位 x86_64 / amd64**，ARM 和其他平台的验证范围见[验证说明](VALIDATION.md)。

## 为什么图标以前是 N

旧版网页使用共用字母占位图标。1.0.6 将登录页、页眉和浏览器标签页统一为各应用的原生图标。若升级后浏览器仍显示旧界面，可刷新页面并核对 FPK 版本。

## 开关为什么以前淡蓝且鼠标一直转圈

旧版成功启用后会禁用“启用”按钮，而禁用样式用了等待光标。1.0.6 改用单开关并区分稳定启用与正在操作的状态；页面按后台确认结果显示，不依靠按钮变淡判断网络是否完成。

## 关闭客户端 TUN 后，NAS 与 Docker 怎么走代理

右侧 **NAS 网络** 启用独立原生 TUN，再把流量交给当前客户端。原版客户端内置 TUN 保持关闭；系统代理、路由和场景选择见[使用指南](USER_GUIDE.md)。

## 自动配置系统代理能覆盖 Docker 吗

不能自动覆盖。它只影响遵循相应桌面用户代理设置的程序。统一接管 NAS 与 Docker 使用右侧 NAS 网络；选择性容器代理需另配可达入口，默认客户端端口只监听 NAS 回环地址。

## V4 绕过大陆是只使用 IPv4 吗

V4 是路由规则版本，与 IPv4／IPv6 选择是不同设置。路由规则负责直连或节点出站；实际行为还受 DNS、节点和目标影响。

## Clash 规则模式会自动生成大陆绕过规则吗

分流使用配置中的实际规则。只有节点列表时，需要补充符合需求的 `rules` 等配置；仅选择规则模式不会凭空生成完整分流。

## 为什么导入格式不再写 VLESS

v2rayN 网页入口改为 **节点分享链接（每行一条）**，由原版客户端处理它支持的 VMess、VLESS、Trojan、Shadowsocks 等链接。Clash 网页入口使用 **Clash / Mihomo YAML**，YAML 可描述多种协议。按原版客户端的导入结果确认，协议参数以实际内核支持为准。

## 图形界面正常，但网络接管无法启用

先确认客户端已激活可用线路，再查看网络状态、接管者和脱敏错误。系统需有唯一可识别 IPv4 默认出口和 RFC1918 私有网关；若存在 `tailscale0`，还要检查 Tailscale 运行状态、在线对端、受信 CLI 及原生守护进程／socket 的识别。检查不通过会拒绝接管，图形界面仍可运行。

## 显示另一客户端接管怎么办

先到该客户端关闭 NAS 网络，确认退出，再开启当前应用。若显示状态待确认或待恢复，先核对提示与管理通道，不重复抢占开关。

## 登录密码是什么、忘了怎么办

没有通用默认密码。各应用在 NAS 初次安装时独立生成，管理员读取 `var/private/access.txt`；网页可在 **访问与安全 → 修改访问密码** 设置新密码。忘记时使用本应用随包管理员重置工具，详见[密码指南](ACCESS.md)。

## 上游更新后为什么网页没变

网页属于飞牛封装，需要在飞牛应用中心安装新版 FPK。右侧“一键更新”更新官方客户端、随附内核/资源及独立网络组件，不改变 FPK 版本号。

## 是否提供节点或家庭网关功能

节点和订阅由使用者自行准备。家庭网关尚未作为当前封装功能配置；部署范围和未验证项目集中在[验证与已知问题](VALIDATION.md)。
