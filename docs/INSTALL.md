# 安装与首次使用

[返回首页](../README.md) · [更新与回滚](UPDATE.md) · [常见问题](FAQ.md)

## 安装前确认

当前提供的是 **v2rayN For FNOS v1.0.5 公开预览版**，目标平台为 fnOS 1.2.1010、Debian 12、x86_64。ARM、其他发行版及其他 fnOS 版本未验证。1.0.5 的本机构建与历史 1.0.4 的 NAS 实测分别记录于 [验证说明](VALIDATION.md)。

- 准备有管理权限的飞牛账号与可用的局域网连接。
- 本版自动识别单一 IPv4 默认出口及 RFC1918 私有网关；多默认出口、无私有网关或 IPv6-only 网络尚不支持自动接管。
- 若存在 `tailscale0`，Tailscale 须运行且至少有一个在线对端供管理路由检查，并提供位于标准系统目录的受信 CLI；无 Tailscale 时使用已识别的 LAN 网关检查。发现失败会拒绝接管，图形界面仍可使用。
- 首次安装需能访问 NAS 已配置的 Debian 软件源，以补齐图形和 Python 依赖。
- 更新已有安装前，保存所需配置与恢复材料。应用 ID 为 `fnv2rayn`，同 ID 的 FPK 会参与同一应用的升级流程。
- 准备自己的节点或配置；本项目不提供线路服务。

## 下载并校验

1. 打开 [v1.0.5 发布页](https://github.com/CyberShadowX/v2rayN-For-FNOS/releases/tag/v1.0.5)。
2. 下载 `fnv2rayn-1.0.5-x86.fpk` 和 `SHA256SUMS.txt`。
3. 计算安装包 SHA-256，与清单中同名文件的记录核对。

Windows PowerShell：

```powershell
Get-FileHash -Algorithm SHA256 ./fnv2rayn-1.0.5-x86.fpk
```

Linux：

```bash
sha256sum ./fnv2rayn-1.0.5-x86.fpk
```

## 在飞牛中安装

1. 打开飞牛 **应用中心**，进入手动安装入口。
2. 选择下载的 FPK，查看安装提示并完成安装。
3. 等待依赖检查与应用启动。首次启动所需时间取决于设备与软件源连接。
4. 使用飞牛桌面的 **v2rayN** 图标进入应用。

## 首次打开与登录

也可在浏览器中打开：

```text
https://<NAS地址>:18111/
```

应用在安装设备上生成自签名证书和独立网页登录口令。浏览器可能提示证书不受信任；先确认目标确实是自己的 NAS，再按浏览器提示处理。

生成的访问资料位于 **fnOS 为该应用分配的 `var` 目录下的 `private/access.txt`**，由 NAS 管理员以相应权限读取。它属于 NAS 上的应用运行数据；本仓库与 Release 不包含该文件，也不存在供所有安装者共用的密码。这里的网页登录口令与 NAS 管理账号密码是两套凭据。

已有安装的口令、配置和证书会保留。设备地址变化或需要调整证书时，先备份并按照明确的维护方案操作，不要清空整个应用数据目录。

## 配置并启用网络

1. 在原版 v2rayN 界面中导入自己的节点或配置。
2. 选择并激活一条可用线路，先确认客户端本身可用。
3. 保持客户端内部 TUN 关闭，系统代理关闭或设为不改变。
4. 开启网页右侧的 **NAS 网络** 开关。
5. 检查接管状态，以及 NAS 本机和需要代理的容器的实际外网访问。

开启接管前，封装只读检查本机默认路由、网卡和管理路径，再使用识别出的网关处理 `.lan` / `.local` DNS。管理路径在运行中失效会触发原有网络收尾流程。无法识别出口或 Tailscale 状态不满足条件时，先检查本机网络配置与脱敏错误信息，不要通过关闭管理保护来强行启动。

两个客户端可以同时运行图形界面，但网络接管互斥。要切换到 [Clash Verge Rev](https://github.com/CyberShadowX/Clash-Verge-For-FNOS)，先关闭当前应用的接管，再启用另一应用。

## 停止与卸载

通过飞牛应用中心或封装入口停止、重启、升级和卸载应用，让生命周期逻辑完成网络与子进程收尾。卸载时按飞牛提示决定是否保留数据；先确认自己的配置和回滚材料已妥善保存。
