# 安装与首次使用

[返回首页](../README.md) · [使用指南](USER_GUIDE.md) · [访问密码](ACCESS.md)

本指南适用于 **v2rayN For FNOS v1.0.6**，manifest 最低 fnOS 声明为 1.2.1010，本轮实测 fnOS 1.2.1011 / Debian 12 / x86_64。具体平台验收范围见[验证说明](VALIDATION.md)。

## 安装前准备

- 准备有管理权限的飞牛账号、可用的局域网或可信远程管理连接。
- 首次安装需访问 NAS 已配置的 Debian 软件源，以补齐图形和 Python 依赖。
- NAS 网络自动接管需要唯一可识别的 IPv4 默认出口和 RFC1918 私有网关；多默认出口、无私有网关、IPv6-only 不在当前自动接管范围内。
- 存在 `tailscale0` 时，Tailscale 需要正常运行、有可用在线对端，并能安全解析其受信 CLI、原生守护进程与本机 socket；检查失败时保留图形界面并拒绝接管。
- 升级已有应用前保存配置和恢复材料。应用 ID 为 `fnv2rayn`，同 ID 的 FPK 进入该应用的升级流程。
- 准备自己的节点或配置，本项目不提供线路服务。

## 下载并校验

1. 打开 [v1.0.6 发布页](https://github.com/CyberShadowX/v2rayN-For-FNOS/releases/tag/v1.0.6)。
2. 下载 `fnv2rayn-1.0.6-x86.fpk` 和 `SHA256SUMS.txt`。
3. 计算 SHA-256，与清单中同名文件核对。

Windows PowerShell：

```powershell
Get-FileHash -Algorithm SHA256 ./fnv2rayn-1.0.6-x86.fpk
```

Linux：

```bash
sha256sum ./fnv2rayn-1.0.6-x86.fpk
```

## 在飞牛中安装

1. 进入飞牛 **应用中心** 的手动安装入口。
2. 选择本应用 FPK，核对名称、版本、架构和安装提示。
3. 等待依赖检查与应用启动，首次所需时间取决于设备和软件源连接。
4. 点击飞牛桌面的 **v2rayN** 图标进入应用。

已有安装在应用中心使用手动上传／升级流程安装新版 FPK；不要把 CLI 返回“已安装”当作已升级。升级前备份，完成后核对封装版本与实际运行界面；本轮已通过原位升级检查并保留原有访问凭据、TLS、节点库和配置。

## 首次打开与登录

```text
https://<NAS地址>:18111/
```

应用在安装设备上生成自签名证书和独立访问密码。先核对自己的 NAS 地址，再处理浏览器证书提示。

访问资料位于该应用的 `var/private/access.txt`，由 NAS 管理员以相应权限读取。没有通用默认密码；两个应用分别生成自己的密码，与 NAS 管理账号密码不同。读取、保存、网页改密和忘记密码的处理见[密码指南](ACCESS.md)。

旧安装的密码、节点与配置在升级时保留。卸载重装是否保留取决于 fnOS 的数据保留选择和实际目录，见[保留规则](ACCESS.md#更新重装与卸载)。

## 导入并启用网络

1. 网页 **导入节点与配置** 中选择本应用支持的 **节点分享链接（每行一条）**；也可直接使用原版客户端的导入功能。
2. 按原版客户端的结果确认导入，并选择、激活可用线路。
3. 保持客户端内置 TUN 关闭；系统代理选择 **不改变系统代理**，路由／代理模式选择 **V4—绕过大陆（Whitelist）**。
4. 打开右侧 **NAS 网络** 的 **网络接管** 开关，等待后台确认 **已启用**。
5. 检查 NAS 本机、需要代理的 Docker 容器和管理连接的实际访问。

网络开关关闭为左侧灰色，启用为右侧蓝色；启停中、状态待确认、待恢复或其他客户端占用时，按页面提示处理，不连续重复点击。详见[网络开关和状态](USER_GUIDE.md#网络开关和状态)。

## 停止和卸载

通过飞牛应用中心或封装入口停止、重启、升级和卸载，让生命周期逻辑完成网络与子进程收尾。卸载前保存需要的配置和访问资料，按飞牛提示决定是否保留应用数据。
