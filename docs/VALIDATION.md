## 升级入口与保留

已有安装通过飞牛应用中心的手动上传／升级入口安装新版 FPK。已安装应用的 CLI 安装命令可能只返回“已安装”，不能把该结果当成升级成功；升级后须核对封装版本和实际载荷。

本轮完成真实原位升级并核对既有凭据、TLS、节点库及配置保留。网页登录改密或管理员重置按[访问指南](ACCESS.md)操作，不通过删除整个应用数据目录找回密码。

## 支持边界

| 项目 | 当前边界 |
| --- | --- |
| 系统与架构 | 本轮实测 fnOS 1.2.1011 / Debian 12 / x86_64；最低声明与历史验证版本分别记录，其他系统和 ARM 未验证 |
| 网络自动发现 | 需要唯一可识别的 IPv4 默认出口和 RFC1918 私有网关；多默认出口、无私有网关和 IPv6-only 不在自动接管范围 |
| Tailscale | 本轮验证原生部署下受信 root 守护进程、CLI 与本机 socket 发现；公开包不固化个人部署路径，识别或权限检查失败即拒绝接管 |
| 容器 | 本轮实际检查 CloudSaver 与 Chromium；其他容器、特殊网络布局和选择性独立代理入口需另外配置或验证 |
| 节点协议 | 原版客户端与内核支持、导入识别和远端连接分别说明；不声称任意节点或参数组合均已验证 |
| 未来上游版本 | 仍需按新发行版本确认兼容性，同版本完整重装不替代未来跨版本验收 |
| 家庭网关 | 当前未配置 |

## 已知问题与专项未验证项目

- 首次 TLS 私钥与证书生成若在两文件发布间遭强杀或断电，可能保留半对状态，初始化会拒绝覆盖并要求管理员恢复；该断电场景尚无实机故障注入结论。
- NAS 整机重启、强杀 root 主控后的完整孤儿进程恢复、HTTP/3／QUIC、视频播放仍需专项验收。
- 既有 IPv6 证据为合成 AAAA 经代理的本地 IPv6 传输，不证明原生远端 IPv6 出口及所有 IPv6 字面量目标。
- UDP STUN、Google/YouTube HTTP 状态不作为 QUIC 或完整视频播放验收的替代。
