## 1.0.4 的历史集成范围

- 目标 NAS 的 100 项测试通过；Windows 主会话为 93 项通过、7 项 Linux 专属测试跳过。
- 两原版图形客户端、接管互斥、客户端完整同版本更新、配置保留与回滚完成验证。
- NAS 本机及既有容器完成 Google HTTP 204、YouTube HTTP 200 和 DNS A/AAAA 检查。
- UDP 证据为 STUN；IPv6 证据为合成 AAAA 经代理的本地 IPv6 传输。
- 带接管重启、重启与停止并发、仅网络守护进程异常后的收尾和恢复场景有历史记录。

这些记录来自私有部署的开发验收。公开文档只保留脱敏摘要，不发布包含个人节点、地址、访问资料或原始连接记录的材料，也不将其改记为新版本测试。

## 保留的限制

| 项目 | 当前边界 |
| --- | --- |
| 守护恢复后的摘要 | 历史 Minor：摘要文字可能短暂滞后，实际状态应结合状态徽标、开关与管理通道核对 |
| NAS 整机重启 | 未验证 |
| 强杀 root 主控进程 | 未验证完整孤儿进程恢复 |
| HTTP/3、QUIC、视频播放 | 未验收，HTTP 状态或 STUN 结果不能代替这些场景 |
| IPv6 | 未证明原生远端 IPv6 出口及所有 IPv6 字面量目标可用 |
| 节点可用性 | 不保证所有协议组合或用户节点都能使用；节点与服务端需分别排查 |
| 未来跨版本更新 | 同版本完整重装与回滚的历史验证不等于未来版本兼容保证 |
| 其他系统及 ARM | 未验证 |
| 家庭网关 | 尚未配置 |

反馈问题时请记录 FPK 版本、客户端/网络组件版本、系统与架构、复现步骤及脱敏错误信息，使用 [问题反馈入口](https://github.com/CyberShadowX/v2rayN-For-FNOS/issues/new/choose)。

## 本次公开版的本机检查

Windows / Python 3.14 的主会话测试共 158 项，151 项通过、7 项 Linux/POSIX 专属检查跳过；包含真实 OpenSSL 新证书 SAN 检查。公开 1.0.5 两个 FPK 已完成本机结构与哈希清单校验，NAS 安装与完整网络流程尚未复测。

证书的私钥与证书是两个文件。首次生成过程中若遭强杀或断电，可能留下半对状态；程序会拒绝覆盖，并保留现场等待人工恢复。该中断场景未作实机故障注入，已有完整证书不会自动重签。

公开版自动网络发现新增的 LAN 默认网关与 Tailscale 在线对端检查，只完成离线模拟验证；不同网卡、无 Tailscale、双网卡等真实设备环境尚未实机验收。多默认出口、无 RFC1918 私有网关和 IPv6-only 不在本版自动接管支持范围内。
