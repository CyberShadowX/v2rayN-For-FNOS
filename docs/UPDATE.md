# 更新、切换与回滚

[返回首页](../README.md) · [安装指南](INSTALL.md)

## 上游更新和封装升级

| 需求 | 使用入口 | 影响 |
| --- | --- | --- |
| 更新 v2rayN 及其随附资源 | 网页右侧“检查更新”“一键更新” | 更新官方稳定客户端整包、随附内核/资源及独立网络组件 |
| 升级本项目的 fnOS 封装 | 飞牛应用中心安装新 FPK | 更新网页管理、运行监督、生命周期与适配逻辑 |
| 恢复保留的程序和配置 | 网页右侧“回滚版本” | 恢复相应程序、网络组件及配置快照 |

FPK 当前公开版本为 **1.0.5 预览版**。上游更新由用户点击触发，不表示已经启用定时无人值守升级；上游程序版本和 FPK 版本分别记录。

## 执行上游更新

1. 记录当前版本和接管者，确认飞牛管理与可信远程连接仍可用。
2. 保存自己需要保留的配置；确认程序与配置快照可用于恢复。
3. 在封装右侧点击 **检查更新**，再按需要点击 **一键更新**。
4. 等待下载、校验、暂存和切换完成。期间原版桌面与外网连接可能短暂中断。
5. 核对实际程序、随附内核、独立网络组件、用户配置和接管状态，再检查 NAS 与相关容器的访问。

请使用封装提供的更新入口。原版客户端内置的更新器不了解 fnOS FPK 生命周期和这里的恢复状态，不承担这套整包升级流程。

## 升级 FPK

在目标 Release 下载本应用的新 FPK，核对 SHA-256，通过飞牛应用中心执行升级。保存旧版本的可信安装包与必要配置，按版本说明检查兼容性。

历史 1.0.4 的同版本整包重装与回滚已完成 NAS 验收；**未来跨版本兼容性需要更新时重新验证**。本次 1.0.5 通用化没有自动替换任何既有 NAS 安装。

## 回滚

封装的 **回滚版本** 会恢复保留的程序版本、独立网络组件及对应配置快照。先单独保存更新后仍希望保留的配置变更，再执行回滚。

回滚完成后核对界面版本、节点和用户设置、网络接管者、NAS/容器访问及管理通道。程序的 `current` / `previous` 引用和配置快照属于恢复材料，清理前先检查引用关系。

## 切换接管者

1. 在当前接管应用中关闭 **NAS 网络**。
2. 确认当前接管已退出。
3. 在另一个客户端中选择并激活线路。
4. 在该应用右侧启用 **NAS 网络**，核对实际状态。

停止、重启和升级应用通过飞牛应用中心或封装入口进行，避免直接杀进程绕过收尾逻辑。
