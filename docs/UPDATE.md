# 更新、切换与回滚

[返回首页](../README.md) · [使用指南](USER_GUIDE.md) · [访问密码](ACCESS.md)

## 先分清两种更新

| 操作 | 更新内容 | 不变的信息 |
| --- | --- | --- |
| 网页右侧“检查更新／一键更新” | 官方稳定客户端整包、随附内核/资源、独立网络组件 | FPK 封装版本号 |
| 飞牛应用中心安装新版 FPK | 网页、网络管理、密码管理、适配与生命周期逻辑 | 保留下来的应用运行数据 |

本轮封装版本为 **1.0.6**。手机式网络开关、原生图标、访问密码管理等网页变化由新 FPK 提供。上游客户端更新由用户点击触发，不表示已启用定时无人值守升级。

## 执行上游更新

1. 记录当前程序版本、接管者，确认管理与可信远程连接仍可用。
2. 保存需要保留的配置，确认程序和配置快照可用于恢复。
3. 点击 **检查更新**，再按需要点击 **一键更新**。
4. 等待下载、校验、暂存和切换完成；桌面和代理访问可能短暂中断。
5. 核对程序、内核、独立网络组件、节点、配置、NAS 网络开关及容器实际访问。

使用封装更新入口，让整包切换与配置快照、恢复流程配合。原版客户端内置更新器不负责飞牛封装的生命周期和这里的恢复状态。检查时已经是最新稳定版，显示无新版本是正常结果。

本轮两应用均完成官方整包真实下载、摘要校验、同版本重装与 GUI／网络恢复，再回滚程序和 profile 并复核联网与原有配置保留；这是当前版本的恢复流程验收，不替代未来上游跨版本兼容性检查。

## 升级 FPK

从[目标 Release](https://github.com/CyberShadowX/v2rayN-For-FNOS/releases/tag/v1.0.6)取得本应用新 FPK，核对摘要，在飞牛应用中心的手动上传／升级入口操作。CLI 安装命令对已有应用可能只提示“已安装”，不能据此判断升级完成。升级前保留旧版可信安装包、配置和必要恢复材料；按版本说明检查系统与架构。

本轮已完成 1.0.4 → 1.0.6 原位升级，按文件字节核对原有网页登录凭据、TLS、节点库与配置保留。网页改密与管理员重置方法见[密码指南](ACCESS.md)，升级不需要删除整个应用数据目录。

## 回滚

封装的 **回滚版本** 恢复保留的程序、网络组件和对应配置快照。先保存更新后仍希望保留的配置变化，再操作并核对恢复结果。

回滚后检查界面版本、节点、规则、实际接管者、NAS/容器访问和管理连接。`current`、`previous` 引用及配置快照属于恢复材料，清理前先检查实际引用。

忘记网页登录密码时使用[访问恢复](ACCESS.md#忘记密码)，不要把程序回滚当作密码重置。若管理员恢复整个应用数据备份，访问资料也以备份内容为准。

## 切换客户端

1. 在当前应用关闭 **NAS 网络**。
2. 等待确认已退出接管；有待恢复提示时先完成恢复。
3. 在另一个客户端选择并激活可用线路。
4. 打开该应用的 NAS 网络开关，核对接管者及实际访问。

两个图形客户端可同时打开，网络接管互斥。停止、重启、升级和卸载通过飞牛应用中心或封装入口进行。

## 每次发布的同步范围

维护者同步源码、中文说明、当前界面脱敏图、版本记录、安装包、对应源码与校验材料。先完成相关源码/浏览器/NAS 检查与独立审查，再创建版本标签和 Release；实际结果写入[验证说明](VALIDATION.md)。保留既有公开标签与附件，程序修正使用新封装版本。
